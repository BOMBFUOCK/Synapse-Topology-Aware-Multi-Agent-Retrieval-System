# 实现智能体画像功能

## 1. 需求分析
- 为智能体添加画像功能，包括简介和关键词摘要
- 在涟漪搜索没有搜到相关内容时，返回所有智能体的简介和关键词摘要

## 2. 实现方案

### 2.1 修改 Agent 类
- 添加 `profile` 属性，存储智能体的简介和关键词摘要
- 添加 `set_profile` 方法，用于设置智能体画像
- 添加 `get_profile` 方法，用于获取智能体画像

### 2.2 修改 RippleSearcher 类
- 在 `search` 和 `search_with_details` 方法中，当没有搜索结果时，返回所有智能体的画像信息
- 遍历所有相关智能体，获取并返回它们的简介和关键词摘要

### 2.3 数据存储设计
- 将智能体画像存储在 Redis 中，使用 `agent:profile:{agent_id}` 作为键
- 画像数据结构：`{"description": "智能体简介", "keywords": ["关键词1", "关键词2"]}`

### 2.4 修改 TopologyClient 类
- 添加获取所有智能体 ID 的方法，用于在没有搜索结果时遍历所有智能体

### 2.5 更新 main.py
- 在创建智能体时，设置智能体的画像信息

## 3. 实现步骤

1. 修改 `synapse/core/db/topology_client.py`，添加获取所有智能体 ID 的方法
2. 修改 `synapse/api.py`，添加智能体画像相关属性和方法
3. 修改 `synapse/core/retriever/ripple_search.py`，在没有搜索结果时返回智能体画像
4. 更新 `main.py`，为智能体设置画像信息
5. 测试功能是否正常工作

## 4. 预期效果
- 智能体可以设置和获取简介及关键词摘要
- 当涟漪搜索没有结果时，返回所有相关智能体的画像信息
- 用户可以通过智能体画像了解每个智能体的专业领域和知识范围
